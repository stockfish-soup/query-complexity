# Changelog

## 0.2.0

- Preserve the `query_complexity` API in a standard `src/` package layout.
- Include the `junta_learning` and `sdp_hierarchy` Python packages in the release.
- Add intersection-free majority SDPs, explicit period-four rank-one witnesses,
  mixed-size learning and multi-bias optimizers.
- Add finite permutation-action irrep-prefix hierarchies, independent reference
  formulations and witness diagnostics.
- Add symmetric-function and triangle-finding builders, reproducible comparisons,
  and explicit memory guards for larger triangle domains.
- Consolidate guides, add installation/API documentation and runnable examples,
  restore the existing MIT license, and correct repository metadata.
- Keep Julia/SymbolicWedderburn sources and research artifacts in the source
  archive and repository, outside the Python runtime wheel.
